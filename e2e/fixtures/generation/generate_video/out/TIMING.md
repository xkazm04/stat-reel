The composition reads the plan and maps frame -> period through a monotone cubic time map, so speed never jumps.

## Strategy
1. **Measure change density per season**: `score = sum of weighted rank inversions among the visible top 10 (row weight 1/(1+0.18 x row), using the order the viewer sees) + 1.5 x entries/exits + sum of |delta value| / 521 (bar movement on the axis) + 0.1 base`.
2. **Frames proportional to score**: clamped to 10-104 frames per season, Gaussian-smoothed (sigma = 1.5), renormalised to the timeline budget (960 frames = 32.0 s).
3. **Dwell bumps** (Gaussian, extra frames) around the events so the cards can be read.
4. **Order**: 3-period centred moving average + hysteresis (an entity overtakes only when ahead by 6% of the value + 0.8857). Labelled on screen: "ORDER: 3-SEASON AVG".
5. **Evenness** (coefficient of variation of changes per second across groups): 0.503 with uniform time, 0.401 warped (excluding the deliberate dwell), 0.416 including dwell.
